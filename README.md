# FundBoard | داشبورد جامع بازارهای مالی

پلتفرم فارسی و راست‌چین برای پایش بازار سرمایه، صندوق‌ها، طلا، ارز و رمزارز.

## فناوری
- PHP 8.1+ (بدون نیاز به Node.js روی هاست)
- MySQL اختیاری برای امکانات کاربری
- JavaScript مدرن
- Apache / cPanel
- ECharts و Lightweight Charts از CDN

## نصب روی هاست
1. محتوای پروژه را در پوشه‌ای مانند `public_html` بارگذاری کنید.
2. فایل `config/config.php` را از روی `config/config.example.php` بسازید و تنظیمات را وارد کنید.
3. در صورت نیاز، دیتابیس MySQL بسازید و `database/schema.sql` را import کنید.
4. پوشه `storage/cache` باید برای PHP قابل نوشتن باشد.
5. آدرس سایت را باز کنید.

## منابع داده
اتصال به منابع بیرونی از طریق Adapterهای سمت سرور انجام می‌شود. MCPهای معرفی‌شده ابزارهای stdio هستند و مستقیماً روی هاست اشتراکی PHP اجرا نمی‌شوند؛ بنابراین این پروژه از لایه اتصال مستقل استفاده می‌کند و در صورت فراهم بودن API یا سرویس واسط، می‌توان Adapter متناظر را فعال کرد.

## وضعیت داده
داده‌های نمونه با برچسب «نمونه» نمایش داده می‌شوند. تا زمانی که منبع زنده تنظیم و تأیید نشده، هیچ عدد نمونه‌ای به‌عنوان قیمت واقعی بازار معرفی نمی‌شود.

## امنیت
- کلیدها و رمزها را در فایل config خارج از web root یا متغیر محیطی نگهداری کنید.
- فایل‌های config و storage نباید از وب قابل دسترسی باشند.
- برای انتشار عمومی، HTTPS فعال کنید.
- این نرم‌افزار توصیه سرمایه‌گذاری ارائه نمی‌کند.
