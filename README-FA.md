# راه‌اندازی فاندبورد روی هاست اشتراکی

## پیش‌نیاز
- PHP نسخه 8.1 یا بالاتر
- افزونه PHP cURL
- Apache با پشتیبانی از htaccess
- MySQL 5.7+ (برای امکانات کاربری و پرتفوی)

## نصب
1. فایل‌ها را در public_html یا پوشه دامنه استخراج کنید.
2. از config/config.example.php یک کپی با نام config/config.php بسازید.
3. آدرس سایت، توکن Tindex و اطلاعات دیتابیس را در config/config.php تنظیم کنید.
4. پوشه storage/cache را برای کاربر PHP قابل نوشتن کنید.
5. برای ساخت جداول، database/schema.sql را در phpMyAdmin اجرا کنید.
6. سایت را با HTTPS باز کنید.

## اتصال منابع معرفی‌شده
پروژه‌های tsetmc-mcp، codal-mcp و iran-crypto-mcp ابزارهای MCP مبتنی بر stdio هستند؛ یعنی برای اجرا به فرایند Python و یک میزبان دائمی نیاز دارند. این ابزارها مستقیماً از PHP روی هاست اشتراکی فراخوانی نمی‌شوند. برای اتصال عملی، یک Bridge کوچک HTTP روی VPS یا سرویس سازگار بسازید و URL آن را در config.php وارد کنید.

- tsetmc_bridge_url: خروجی JSON داده بورس
- codal_bridge_url: خروجی JSON اطلاعیه‌ها
- crypto_bridge_url: خروجی JSON بازار رمزارز
- bridge_bearer_token: توکن مشترک محافظت از Bridge

## وضعیت نسخه فعلی
رابط کاربری و اسکلت API آماده است. صفحات تحلیلی، نمودارهای نمایشی و ساختار اولیه Backend پیاده شده‌اند. داده‌های عددی بازار عمداً تا زمان تأیید اتصال منبع خالی می‌مانند. ورود کاربر، مدیریت عملی پرتفوی و فیلترهای ذخیره‌شونده در این نسخه هنوز تکمیل نشده‌اند.

## امنیت
- config.php را هرگز در GitHub قرار ندهید.
- توکن API را در JavaScript قرار ندهید.
- HTTPS را فعال کنید.
- قبل از فعال‌سازی ثبت‌نام عمومی، CSRF، محدودیت نرخ و تأیید ایمیل اضافه کنید.
