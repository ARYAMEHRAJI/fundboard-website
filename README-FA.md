# فاندبورد | نصب و اجرا فقط روی هاست cPanel

## معماری اجرایی
این نسخه برای اجرا روی همان هاست اشتراکی طراحی شده است:
- PHP 8.1+ و افزونه cURL برای API و دریافت داده
- MySQL/MariaDB برای ذخیره‌سازی اطلاعات ساختاریافته
- فایل‌کش داخل storage/cache برای کاهش درخواست به منابع بیرونی
- Cron Jobs خود cPanel برای تازه‌سازی دوره‌ای کش
- JavaScript و ECharts برای داشبورد و نمودارها

برای اجرای سایت نیازی به VPS، Cloudflare Workers، GitHub Actions یا سرویس دائمی خارجی نیست. مخزن GitHub فقط محل نگهداری سورس و دریافت ZIP است؛ پس از آپلود، سایت روی هاست اجرا می‌شود.

## پیش‌نیازهای هاست
1. PHP 8.1 یا بالاتر
2. افزونه‌های cURL و mbstring فعال
3. امکان اتصال خروجی HTTPS از PHP به منابع داده
4. Apache با پشتیبانی از .htaccess
5. MySQL 5.7+ یا MariaDB سازگار
6. Cron Jobs در cPanel (برای تازه‌سازی خودکار؛ در صورت نبود Cron، کش هنگام درخواست کاربر تازه می‌شود)

## نصب
1. ZIP پروژه را در پوشه دامنه، معمولاً public_html، استخراج کنید.
2. از config/config.example.php یک کپی با نام config/config.php بسازید.
3. مقدار app.url را برابر آدرس HTTPS سایت قرار دهید.
4. توکن Tindex را در sources.tindex_token وارد کنید؛ این مقدار برای داده‌های Tindex لازم است.
5. دسترسی نوشتن PHP را برای storage/cache و storage/logs فعال کنید.
6. فایل database/schema.sql را از طریق phpMyAdmin وارد کنید.
7. دامنه را با HTTPS باز کنید.

## تازه‌سازی خودکار با Cron در cPanel
در cPanel وارد Cron Jobs شوید و یک کار زمان‌بندی‌شده اضافه کنید. نمونه اجرای هر ۵ دقیقه:

    */5 * * * * /usr/local/bin/php /home/CPANEL_USER/public_html/cron/refresh.php

مسیر PHP و مسیر home را از شرکت هاستینگ یا بخش Select PHP Version/Terminal بگیرید؛ مسیر بالا نمونه است و ممکن است در هاست شما متفاوت باشد. برای شروع می‌توان زمان‌بندی را هر ۱۰ یا ۱۵ دقیقه گذاشت تا فشار و مصرف منابع پایین بماند.

این Cron فقط cache endpointهای Tindex را گرم می‌کند. اگر Cron غیرفعال باشد، API همچنان با کش هنگام درخواست کاربر کار می‌کند. لاگ اجرا در storage/logs ذخیره می‌شود.

## اتصال Tindex
آدرس پایه https://tindex.app است و احراز هویت با هدر Bearer انجام می‌شود. توکن را فقط در config/config.php نگه دارید و هرگز آن را در فایل‌های عمومی یا GitHub قرار ندهید.

Endpointهای فعلی پروژه:
- api/?action=overview
- api/?action=board&key=currency
- api/?action=board&key=gold
- api/?action=board&key=crypto
- api/?action=board&key=market
- api/?action=movers
- api/?action=history&slug=GOLD-18K&range=3m
- api/?action=category&slug=precious-metals

## وضعیت اتصال منابع

### TSETMC
آداپتور PHP مستقیم برای ابزارهای زیر اضافه شده است:
- جست‌وجوی نماد و ناشر
- تابلوی قیمت، اطلاعات روز، حجم، ارزش و تعداد معاملات
- برترین‌های بورس، فرابورس، حق‌تقدم و اوراق بر اساس رشد، افت، حجم، ارزش یا تعداد معاملات
- پنج سطح سفارش خرید و فروش
- تاریخچه روزانه قیمت تا ۵۰۰ روز
- جریان خرید و فروش حقیقی و حقوقی تا ۵۰۰ جلسه
- وضعیت شاخص کل، هم‌وزن و شاخص‌های صنایع
- تاریخچه شاخص‌ها

قیمت‌های TSETMC در پاسخ خام ریال هستند. پیش از نمایش در هر بخش باید تبدیل ریال/تومان صریح باشد. دسترسی TSETMC به شبکه و IP هاست وابسته است؛ در صورت پاسخ 403، ممکن است هاست نتواند مستقیماً به CDN آن دسترسی پیدا کند.

### Codal
آداپتور PHP مستقیم برای این قابلیت‌ها اضافه شده است:
- جست‌وجوی شرکت و صندوق
- جست‌وجوی اطلاعیه‌ها با نماد، گروه، نوع، عنوان، تاریخ شمسی، دوره مالی و شماره پیگیری
- فهرست گروه‌های اطلاعیه
- دریافت سال‌های مالی ناشر
- دریافت اطلاعات پایه اطلاعیه، لینک PDF/Excel و استخراج جدول‌های صفحه صورت مالی در مواردی که ساختار صفحه قابل‌خواندن باشد

برای جلوگیری از محدودیت کدال، درخواست‌ها با فاصله حداقل حدود ۲ ثانیه ارسال می‌شوند و پاسخ‌ها کش می‌شوند. کدال ممکن است IP هاست خارج از ایران را مسدود کند یا کپچا ارائه دهد؛ در این صورت اتصال مستقیم از آن هاست عملی نخواهد بود.

### بازار رمزارز و ۱۲ صرافی
فهرست قابلیت‌های ۱۲ صرافی مرجع در پنل قرار گرفته است. در این نسخه دریافت قیمت و مقایسه قیمت به‌صورت آزمایشی برای سه صرافی نوبیتکس، والکس و بیت‌پین پیاده‌سازی شده است؛ فهرست بازارها نیز برای همین سه صرافی در دسترس است.

قابلیت‌های زیر در فهرست ابزارها قرار دارند اما آداپتور مستقیمشان هنوز تکمیل نشده است:
- دفتر سفارش تا ۲۰ سطح
- معاملات اخیر
- کندل‌های ۱۵ دقیقه، یک‌ساعته، چهارساعته و روزانه
- برترین رشدها و افت‌ها با فیلتر نقدشوندگی
- بهترین محل اجرای سفارش و محاسبه لغزش
- اختلاف قیمت و اسکن فرصت آربیتراژ
- کارمزد معاملات و شبکه‌ها و هزینه برداشت
- نمای کلی بازار

### نکته اجرایی
این سه MCP در اصل برنامه‌های stdio هستند و روی cPanel به‌عنوان سرویس دائمی اجرا نمی‌شوند. قابلیت‌های موردنیاز به‌صورت آداپتورهای PHP مستقل بازسازی شده‌اند. کد آماده‌شده باید روی هاست واقعی آزمایش شود؛ موفقیت درخواست از محیط توسعه تضمین‌کننده دسترسی IP هاست نیست. ابزارهایی که هنوز متصل نشده‌اند به‌جای نمایش داده ساختگی، پیام عدم اتصال می‌دهند.

## امنیت
- فایل config/config.php را در GitHub منتشر نکنید.
- مسیرهای config/، database/ و storage/ باید از وب مسدود باشند.
- Cron از طریق CLI اجرا می‌شود و درخواست HTTP مستقیم به آن پاسخ 404 می‌دهد.
- از HTTPS استفاده کنید.
- برای داده‌های مالی، واحد ریال/تومان و تاریخ شمسی/میلادی را صریح نگه دارید.

## وضعیت توسعه
- رابط فارسی RTL و واکنش‌گرا: نسخه اولیه
- API و کش Tindex: پیاده‌سازی اولیه
- TSETMC: آداپتورهای اصلی PHP پیاده‌سازی شده؛ نیازمند آزمایش دسترسی از هاست
- Codal: جست‌وجو، ناشر، گروه‌ها، سال مالی و خواندن جدول‌های صورت مالی پیاده‌سازی اولیه
- رمزارز: قیمت/مقایسه و فهرست بازار سه صرافی پیاده‌سازی اولیه؛ سایر ابزارها در صف توسعه
- اجرای Cron روی cPanel: فایل آماده؛ نیازمند تنظیم مسیر PHP و زمان‌بندی در هاست
- رتبه‌بندی چندپروفایلی صندوق‌ها و تحلیل کامل هم‌پوشانی پرتفوی: مراحل توسعه بعدی؛ موتور تحلیل ترکیبی سهام/ETF و رادار رویدادهای کدال در پروفایل پیاده‌سازی شده است

این نرم‌افزار ابزار نمایش و تحلیل داده است و توصیه سرمایه‌گذاری محسوب نمی‌شود.


## قابلیت‌های عملیاتی افزوده‌شده

- جستجوی یکپارچه نمادهای بورس و ETF از طریق TSETMC؛ نوع ابزار از اطلاعات بازگشتی منبع تشخیص داده می‌شود.
- پروفایل سهم و ETF: قیمت آخرین معامله و پایانی، باز/بیشینه/کمینه، حجم و ارزش معاملات، تاریخچه قیمت، نمودار کندلی، میانگین متحرک ۲۰، حجم و RSI ۱۴.
- پروفایل ETF قیمت تابلو و NAV صدور/ابطال را در صورت پاسخ‌گویی endpointهای TSETMC نمایش می‌دهد. حباب با اختلاف قیمت و NAV محاسبه می‌شود؛ اگر یکی از دو مقدار در دسترس نباشد، خالی می‌ماند. ترکیب دارایی، AUM و جریان صدور/ابطال به منبع تخصصی صندوق نیاز دارند و جعل یا تخمین زده نمی‌شوند.
- دیده‌بان بازار TSETMC با فیلتر بورس، فرابورس، حق‌تقدم و اوراق بدهی و مرتب‌سازی رشد/افت/حجم/ارزش/تعداد معاملات.
- مقایسه حداکثر چهار نماد بر اساس تاریخچه قیمت TSETMC.
- پرتفوی محلی در مرورگر: ثبت نماد، تعداد و بهای تمام‌شده و محاسبه ارزش/سودوزیان بر اساس آخرین قیمت قابل دریافت. داده‌ها بین دستگاه‌ها همگام نمی‌شوند و با پاک‌شدن داده‌های مرورگر از بین می‌روند.
- بازار طلا و ارز: کارت‌های قیمت و نمودارهای spark از Tindex.
- رمزارز: تیکر و فهرست بازارها در نوبیتکس/والکس/بیت‌پین؛ دفتر سفارش و معاملات اخیر در نوبیتکس و والکس؛ کندل‌های OHLC در والکس؛ برترین‌ها، مقایسه قیمت، برآورد عمق اجرای سفارش و اختلاف قیمت.
- نمودارهای نمونه از داشبورد اصلی حذف شده‌اند؛ نمودار فقط با داده واقعی منبع ترسیم می‌شود.

## محدودیت‌های داده و استقرار

1. API توسعه‌دهندگان Tindex برای چهار تابلوی ارز، طلا، رمزارز و بورس/انرژی مستند است و دیتابیس جامع صندوق‌ها را ارائه نمی‌کند. برای حباب دقیق، AUM، جریان پول صندوق‌ها، ترکیب دارایی و رتبه‌بندی ریسک باید یک منبع داده تخصصی صندوق یا فایل/سرویس Bridge معتبر فراهم شود. قیمت تابلو و NAV صدور/ابطال ETF از TSETMC قابل دریافت است.
2. پروفایل ETF در حال حاضر پروفایل معاملاتی نماد ETF در TSETMC است؛ نباید آن را با پروفایل کامل صندوق شامل NAV و پرتفوی اشتباه گرفت.
3. تیکر بیت‌پین فعال است؛ orderbook/trades/candles بیت‌پین در این نسخه متصل نیست.
4. کدهای صرافی‌های دیگر در فهرست دیده می‌شوند، اما تا زمان پیاده‌سازی و تست آداپتور، قابلیت‌هایشان فعال اعلام نشده است.
5. همه درخواست‌های بیرونی از PHP روی cPanel انجام می‌شوند. هاست باید امکان خروج HTTPS به دامنه‌های منابع را داشته باشد. دسترسی شبکه واقعی cPanel هنوز نیازمند تست است.
6. پرتفوی در این نسخه localStorage مرورگر است؛ برای حساب کاربری، ذخیره ابری و همگام‌سازی، باید اتصال امن MySQL و سامانه احراز هویت فعال شود.
7. کدها هنوز روی cPanel واقعی و با توکن‌های کاربر آزمایش نشده‌اند. پس از آپلود، ابتدا فایل config/config.php را از نمونه بسازید، توکن Tindex را وارد کنید و سپس API را در همان هاست بررسی کنید.


## پروفایل هوشمند دارایی و اتصال کدال
- پروفایل سهام و ETF از TSETMC، همراه با نمودار قیمت، حجم و شاخص‌های تکنیکال.
- در پروفایل سهام، جستجوی شرکت و اطلاعیه‌های اخیر کدال بر اساس نماد انجام می‌شود.
- در پروفایل ETF، داده‌های قابل‌دسترسی TSETMC برای قیمت و NAV و اطلاعیه‌های کدال نمایش داده می‌شوند.
- موتور تحلیل ترکیبی، تاریخچه ۵۰۰روزه TSETMC را مستقل از بازه نمودار می‌خواند و بازده ۱ هفته/۱ ماه/۳ ماه/۱ سال، نوسان سالانه‌شده، بیشترین افت، RSI، میانگین متحرک ۲۰، نسبت حجم ۲۰ به ۶۰ روز و خالص جریان حقیقی ۵ و ۲۰ جلسه را محاسبه می‌کند.
- موتور، آخرین صورت مالی قابل‌شناسایی را از کدال باز می‌کند و در صورت پشتیبانی صفحه، اطلاعات دوره و برش‌هایی از جدول‌های ساختاریافته را کنار قیمت و جریان پول نمایش می‌دهد. لینک صفحه، PDF و Excel اصلی نیز در صورت وجود حفظ می‌شوند.
- قابلیت خلاقانه «واگرایی قیمت و پول» رشد/افت قیمت را با خالص خرید حقیقی مقایسه می‌کند؛ همچنین رویدادهای کدال در کنار شاخص‌های بازار قرار می‌گیرند. این پرچم‌ها هشدار تحلیلی توصیفی‌اند و سیگنال خرید/فروش نیستند.
- داده‌های استخراج‌شده ممکن است با تغییر قالب صفحات کدال یا محدودیت دسترسی هاست ناقص باشند؛ در این حالت لینک مرجع کدال نمایش داده می‌شود.


## اتاق تحلیل ترکیبی دارایی
پروفایل سهام و صندوق از لایه پژوهش مشترک استفاده می‌کند:
- تاریخچه بلندتر TSETMC برای محاسبه بازده ۱ هفته، ۱ ماه، ۳ ماه و ۱ سال، نوسان سالانه‌شده، بیشترین افت، RSI، میانگین متحرک و نسبت حجم ۲۰ به ۶۰ جلسه.
- جریان خالص ارزش و حجم خرید حقیقی از تاریخچه معاملات حقیقی/حقوقی TSETMC در ۵ و ۲۰ جلسه و نمودار ۳۰ جلسه‌ای.
- پرچم‌های تحلیلی توصیفی برای وضعیت نسبت به میانگین ۲۰ جلسه، محدوده RSI، جهش حجم و واگرایی قیمت با جریان پول حقیقی.
- طبقه‌بندی اطلاعیه‌های کدال به رویدادهایی مانند صورت مالی، فعالیت ماهانه، افشای بااهمیت، افزایش سرمایه، مجمع و قرارداد.
- استخراج جداول آخرین صورت مالی و گزارش فعالیت ماهانه در صورت پشتیبانی صفحه کدال؛ نمایش جدول‌ها و لینک صفحه/PDF/Excel رسمی.
- دکمه «تحلیل گزارش» برای بازکردن محتوای ساختاریافته اطلاعیه کدال داخل پروفایل.
- بازده و ریسک فقط از تعداد مشاهدات موجود محاسبه می‌شود؛ اگر تاریخچه کافی نباشد، مقدار خالی نمایش داده می‌شود و داده مصنوعی جایگزین نمی‌شود.

محدودیت مهم: این لایه به دسترسی خروجی هاست cPanel به CDN تSETMC و دامنه‌های Codal وابسته است. اگر هاست خارج از ایران باشد یا منبع درخواست را مسدود کند، برخی کارت‌ها و نمودارها با پیام عدم دسترسی نمایش داده می‌شوند. خروجی استخراج جدول‌های کدال نیز به قالب همان اطلاعیه وابسته است.


## اتاق هوش بازار و تحلیل چندمنبعی

صفحه «اتاق هوش بازار» سه جریان داده را در یک نمای واحد کنار هم می‌گذارد:
- **TSETMC:** نقشه حرارتی بازار بر اساس ارزش معاملات، تابلو نمادهای پرتحرک و تغییرات قیمت.
- **Codal:** آخرین اطلاعیه‌های ناشران با لینک مستقیم به اطلاعیه رسمی.
- **Tindex:** شاخص‌های منتخب بازار طلا، ارز، رمزارز و بورس در صورت فعال بودن توکن.

پروفایل سهم و ETF علاوه بر نمودار قیمت، یک اتاق تحلیل ترکیبی دارد:
- بازده یک هفته، یک ماه، سه ماه و یک سال از تاریخچه مستقل ۵۰۰روزه/۳۶۵روزه محاسبه می‌شود؛ تغییر بازه نمودار، مبنای محاسبه شاخص‌های سالانه را عوض نمی‌کند.
- نوسان سالانه‌شده، بیشترین افت از سقف، RSI، میانگین متحرک ۲۰روزه و نسبت حجم ۲۰ به ۶۰ جلسه محاسبه می‌شوند.
- جریان خالص خرید حقیقی ۵ و ۲۰ جلسه از تاریخچه حقیقی/حقوقی TSETMC استخراج و نمودار ۳۰ جلسه‌ای آن ترسیم می‌شود.
- موتور «واگرایی قیمت و پول» رشد/افت قیمت را با جریان حقیقی مقایسه می‌کند؛ این فقط یک پرچم پژوهشی است و به معنی ورود یا خروج قطعی پول هوشمند نیست.
- رویدادهای کدال بر اساس موضوع دسته‌بندی می‌شوند. آخرین صورت مالی و گزارش فعالیت ماهانه، در صورت پشتیبانی صفحه کدال، برای استخراج جدول‌ها دریافت می‌شود.
- در صفحه مقایسه دارایی‌ها، نمودار بازده نرمال‌شده، نوسان، بیشترین افت و ماتریس همبستگی بازده روزانه برای حداکثر چهار نماد نمایش داده می‌شود.
- مرکز صندوق‌ها از فهرست صندوق‌های TSETMC تغذیه می‌شود و امکان فیلتر بر اساس نوع صندوق و ورود به پروفایل هر ETF را دارد.

تمام محاسبات مشتق‌شده در فاندبورد انجام می‌شوند؛ داده خام، داده محاسباتی و تفسیر تحلیلی باید در UI از هم قابل تشخیص باشند. اگر یک منبع داده یا صفحه کدال قابل دسترسی نباشد، فاندبورد باید آن بخش را خالی/دارای خطا نشان دهد و داده ساختگی تولید نکند.
