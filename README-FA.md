# فاندبورد | نصب و اجرا فقط روی هاست cPanel

## معماری اجرایی
این نسخه برای اجرا روی همان هاست اشتراکی طراحی شده است:
- PHP 8.1+ و افزونه cURL برای API و دریافت داده
- MySQL/MariaDB برای ذخیره‌سازی اطلاعات ساختاریافته
- فایل‌کش داخل storage/cache برای کاهش درخواست به منابع بیرونی
- Cron Jobs خود cPanel برای تازه‌سازی دوره‌ای کش
- JavaScript و ECharts برای داشبورد و نمودارها

برای اجرای سایت نیازی به VPS، Cloudflare Workers، GitHub Actions یا سرویس دائمی خارجی نیست. مخزن GitHub فقط محل نگهداری سورس و دریافت ZIP است؛ پس از آپلود، سایت روی هاست اجرا می‌شود.

## پیش‌نیازهای هاست
1. PHP 8.1 یا بالاتر
2. افزونه cURL فعال
3. امکان اتصال خروجی HTTPS از PHP به منابع داده
4. Apache با پشتیبانی از .htaccess
5. MySQL 5.7+ یا MariaDB سازگار
6. Cron Jobs در cPanel (برای تازه‌سازی خودکار؛ در صورت نبود Cron، کش هنگام درخواست کاربر تازه می‌شود)

## نصب
1. ZIP پروژه را در پوشه دامنه، معمولاً public_html، استخراج کنید.
2. از config/config.example.php یک کپی با نام config/config.php بسازید.
3. مقدار app.url را برابر آدرس HTTPS سایت قرار دهید.
4. توکن Tindex را در sources.tindex_token وارد کنید؛ این مقدار برای داده‌های Tindex لازم است.
5. دسترسی نوشتن PHP را برای storage/cache و storage/logs فعال کنید.
6. فایل database/schema.sql را از طریق phpMyAdmin وارد کنید.
7. دامنه را با HTTPS باز کنید.

## تازه‌سازی خودکار با Cron در cPanel
در cPanel وارد Cron Jobs شوید و یک کار زمان‌بندی‌شده اضافه کنید. نمونه اجرای هر ۵ دقیقه:

    */5 * * * * /usr/local/bin/php /home/CPANEL_USER/public_html/cron/refresh.php

مسیر PHP و مسیر home را از شرکت هاستینگ یا بخش Select PHP Version/Terminal بگیرید؛ مسیر بالا نمونه است و ممکن است در هاست شما متفاوت باشد. برای شروع می‌توان زمان‌بندی را هر ۱۰ یا ۱۵ دقیقه گذاشت تا فشار و مصرف منابع پایین بماند.

این Cron فقط cache endpointهای Tindex را گرم می‌کند. اگر Cron غیرفعال باشد، API همچنان با کش هنگام درخواست کاربر کار می‌کند. لاگ اجرا در storage/logs ذخیره می‌شود.

## اتصال Tindex
آدرس پایه https://tindex.app است و احراز هویت با هدر Bearer انجام می‌شود. توکن را فقط در config/config.php نگه دارید و هرگز آن را در فایل‌های عمومی یا GitHub قرار ندهید.

Endpointهای فعلی پروژه:
- api/?action=overview
- api/?action=board&key=currency
- api/?action=board&key=gold
- api/?action=board&key=crypto
- api/?action=board&key=market
- api/?action=movers
- api/?action=history&slug=GOLD-18K&range=3m
- api/?action=category&slug=precious-metals

## وضعیت اتصال منابع و محدودیت مهم
### TSETMC MCP
مخزن مرجع، ابزارهای جست‌وجوی نماد، مظنه، برترین‌های بازار، عمق پنج سطح سفارش، تاریخچه روزانه، معاملات حقیقی/حقوقی و شاخص‌ها را معرفی می‌کند. این ابزارها هنوز به‌طور کامل در این وب‌سایت بازپیاده‌سازی و متصل نشده‌اند.

### Codal MCP
مخزن مرجع، جست‌وجوی ناشر و اطلاعیه، خواندن نامه و صورت‌های مالی جدولی، گزارش فعالیت ماهانه، پیوست‌ها، گروه/نوع اطلاعیه و سال مالی را معرفی می‌کند. این قابلیت‌ها هنوز به‌طور کامل در وب‌سایت پیاده‌سازی نشده‌اند. کدال ممکن است در برابر درخواست‌های پرتعداد IP را موقتاً محدود کند؛ باید درخواست‌ها محدود و کش شوند.

### Iran Crypto MCP
مخزن مرجع، مقایسه قیمت در ۱۲ صرافی ایرانی، تیکر، دفتر سفارش، معاملات، کندل‌ها، برترین رشد/افت، فهرست بازارها، تخمین لغزش سفارش، اختلاف قیمت بین صرافی‌ها، کارمزد و شبکه برداشت را معرفی می‌کند. این قابلیت‌ها هنوز در سایت به‌طور کامل پیاده‌سازی نشده‌اند.

توجه: این سه MCP از نوع stdio هستند و نصب مستقیم آن‌ها روی cPanel برای اجرای وب‌سایت لازم یا مناسب نیست. قابلیت‌های موردنیاز باید به‌صورت اتصال مستقیم PHP به APIهای عمومی هر منبع بازسازی شوند. سازگاری دسترسی شبکه هاست با TSETMC و Codal باید روی خود هاست آزمایش شود؛ برخی منابع ممکن است IP یا شبکه را محدود کنند. هیچ داده‌ای تا زمان دریافت واقعی نباید به‌عنوان داده زنده نمایش داده شود.

## امنیت
- فایل config/config.php را در GitHub منتشر نکنید.
- مسیرهای config/، database/ و storage/ باید از وب مسدود باشند.
- Cron از طریق CLI اجرا می‌شود و درخواست HTTP مستقیم به آن پاسخ 404 می‌دهد.
- از HTTPS استفاده کنید.
- برای داده‌های مالی، واحد ریال/تومان و تاریخ شمسی/میلادی را صریح نگه دارید.

## وضعیت توسعه
- رابط فارسی RTL و واکنش‌گرا: نسخه اولیه
- API و کش Tindex: پیاده‌سازی اولیه
- اجرای Cron روی cPanel: فایل آماده؛ نیازمند تنظیم مسیر PHP و زمان‌بندی در هاست
- اتصال کامل تمام ابزارهای سه MCP: در دست توسعه، هنوز کامل نیست
- رتبه‌بندی صندوق، غربالگر، مقایسه پیشرفته، پرتفوی کاربر و هشدارها: مراحل توسعه بعدی

این نرم‌افزار ابزار نمایش و تحلیل داده است و توصیه سرمایه‌گذاری محسوب نمی‌شود.
